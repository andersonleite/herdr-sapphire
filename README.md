# herdr-sapphire

Layout `sapphire` do [Herdr](https://herdr.dev) com o prompt de shell que o acompanha.

- `shell/prompt.zsh` — prompt zsh puro (caminho, branch git, status do último comando, duração). Sem dependências.
- `install.sh` — instala nesta máquina: adiciona uma linha `source` ao `~/.zshrc`. Idempotente.

Instalar: `./install.sh` e abrir um terminal novo.

O layout em si (`layouts/`, `mods/`, `themes/`, `RECIPE.md`, `preview.png`) será adicionado quando for publicado.
